# 设计计划时间表生成器 v4.5 中国院版

> 作者：JaJa+AI

## 项目简介

设计计划时间表生成器是一款面向建筑工程设计项目管理的小型桌面工具，用于**自动生成专业配合/设计节点计划 Excel 表**。

本版本为 **v4.5 中国院版**：基于 v5.3.3 裁剪，仅保留覆写节点链路，内置节点体系与配合内容依据 **《建筑工程设计项目专业配合规定》**（中国建筑设计研究院）编制，覆盖初步设计与施工图设计两个阶段的专业协调会、专业间反提资料、作业图、会审会签等全套配合流程，可直接生成带日历样式、可打印的 Excel 专业配合进度表。
